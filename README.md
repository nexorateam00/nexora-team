# NEXORA TEAM — Website

A responsive, dark premium agency website built with React + Vite.

## Requirements
- Node.js (LTS)
- npm

## Run locally
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open the terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite (usually http://localhost:5173).

## Before publishing — important
Open `src/main.jsx` and replace:
- `hello@nexorateam.com` with your real business email.
- `212600000000` with your WhatsApp number (country code + number, digits only).

Also update social links in the footer with your real accounts.

## Build for production
```bash
npm run build
```
The production files will be generated in `dist/`.

## Deploy
You can push the project to GitHub and import the repository into Vercel.
This is a frontend-only website; no database or backend is required for this first version.
